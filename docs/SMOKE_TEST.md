# Smoke Test Checklist — How To Work With Me

**Goal:** Confirm core flow works in ~10 minutes. Run after any polish or deploy.

**Prerequisites:** Dev server running (`npm run dev`), `.env.local` with Clerk, Supabase, and OpenAI keys.

---

## 1. Pre-flight (1 min)

- [ ] **Check + build:** From project root run:
  ```bash
  npm run check
  npm run build
  ```
  Both complete with no errors.

- [ ] **Dev server:** `npm run dev` → open http://localhost:3000

---

## 2. Auth (2 min)

- [ ] **Home:** `/` loads; sign-in/sign-up links visible.
- [ ] **Sign in:** Click sign in → complete sign-in → land on `/app` or `/auth/callback` then `/app`.
- [ ] **Dashboard:** `/app` shows dashboard (empty or list of manuals).

---

## 3. Questionnaire → Generate (3 min)

- [ ] **New manual:** From dashboard, start “New manual” (or go to `/app/new`).
- [ ] **Answers:** Fill at least one question; wait for “Saved” or no error.
- [ ] **Navigate:** Use Next/Back; no 404 or network errors.
- [ ] **Last step:** Fill all questions; click **Convert to manual**.
- [ ] **Generate page:** Lands on `/app/new/generate` with context selector.
- [ ] **Generate:** Click “Generate manual” → “Generating…” → redirect to manual page (or clear error if config missing).

---

## 4. Manual page actions (3 min)

- [ ] **Manual view:** Manual page shows title, version, content, and action buttons.
- [ ] **Export PDF:** Click “Export PDF” → file downloads (or error banner); no blob-tab issue.
  - **PDF visual check:** Open the downloaded PDF and verify:
    - Title page has stacked title “HOW TO / WORK WITH / ME”, subtitle, and “Generated by How To Work With Me” with date.
    - Body pages have readable sections: headings stand out, paragraphs are wrapped (not cut off).
    - Bullet and numbered lists are indented properly with hanging indent.
    - Page numbers (“Page 2”, “Page 3”, …) and generated date appear in footer on body pages.
- [ ] **Share:** Click “Create share link” → share URL appears; copy works.
- [ ] **Revoke:** Click “Revoke” on a share link → link marked revoked (or list updates).
- [ ] **Regenerate:** Click “Regenerate manual” → job runs → redirect to new manual or error shown.

---

## 5. Share view + Delete (1 min)

- [ ] **Shared view:** Open the share URL in incognito (or different browser) → manual content visible; no sign-in required.
- [ ] **Delete manual:** On manual page, click “Delete my manual” → confirm → redirect to `/app`.
- [ ] **Delete all data (optional):** From app area, use “Delete all my data” if present → confirm (and 2-step if implemented) → data cleared.

---

## 6. Quick API sanity (optional)

- [ ] **Health:** `GET /api/health` returns 200 (no auth).
- [ ] **Protected:** Logged out, `/app` redirects to sign-in.

---

## Pass criteria

- All checked items pass.
- No console errors or repeated 404s during questionnaire or manual actions.
- Export triggers download; share creates and revokes links; regenerate produces a new version or clear error.

## If something fails

- Note: page, action, and any error message.
- Run `npm run check` and `npm run build` again.
- Check dev server logs for API errors (no PII in logs).
- See README/DEPLOY for env and troubleshooting.
